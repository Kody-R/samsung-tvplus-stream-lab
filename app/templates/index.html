Isolation workflow

  1. Use the direct Samsung/FAST media URL when possible. This bypasses IPTV Merge Manager entirely.
  2. Run Copy → Null to reproduce the baseline failure.
  3. Run Permissive Copy → Null to test the same path with -extension_picky 0.
  4. If permissive copy survives SSAI transitions, repeat with Normalized HLS — Permissive.
  5. For Continuous TS, open the displayed stream.ts URL in VLC/Jellyfin. The connection automatically creates a diagnostic session.
  6. Download the session bundle after a freeze/EOF and inspect events.jsonl, child manifest snapshots, FFmpeg log and progress.

Continuous TS — Permissive is also available at stream-permissive.ts so we can apply the same input-side experiment to the TS relay.
