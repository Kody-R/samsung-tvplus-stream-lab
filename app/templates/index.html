How v0.2.2 works

  1. Add a full playlist and optional XMLTV guide on Sources.
  2. Refresh it. New channels are imported but remain unselected.
  3. Use Channels to search/filter and select only what Jellyfin should receive.
  4. Selected channels default to Normalized HLS · Permissive.
  5. FFmpeg starts on demand when Jellyfin opens a channel, then stops after the HLS relay goes idle.

Jellyfin setup

  1. Add an M3U Tuner using /playlist.m3u.

  3. Refresh Jellyfin Live TV channels and guide data after changing your selection.

A/V Sync Tuning

-dts_delta_threshold is now adjustable without rebuilding Stream Lab. The value is in seconds and applies when a new FFmpeg session starts. Existing relays keep the value they started with.

Quick DTS presets:

For the current Samsung SSAI issue, 60 seconds is the v0.2.2 starting point. The new Normalized + Audio Sync · Permissive profile keeps H.264 video as stream-copy while re-encoding/resynchronizing AAC audio.
