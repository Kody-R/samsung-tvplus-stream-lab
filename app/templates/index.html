Jellyfin setup

  1. In Jellyfin, add an M3U Tuner using the Stream Lab /playlist.m3u URL shown on the Streams tab.
  2. Add an XMLTV guide data provider using the Stream Lab /guide.xml URL.
  3. For real programme listings, configure each stream with an XMLTV source URL and the channel ID used by that source. Streams without XMLTV still receive a valid channel entry in the generated guide.
  4. Keep the stream playback profile on Normalized HLS — Permissive for the Samsung SSAI test path.

Isolation workflow

  1. Use the direct Samsung/FAST media URL when possible.
  2. Run Copy → Null · Permissive to validate input acceptance.
  3. Run Normalized HLS · Permissive through SSAI transitions.
  4. Let Jellyfin consume the generated M3U and XMLTV endpoints.
  5. If playback freezes, leave Stream Lab running, test the same HLS URL in VLC, then download the session bundle.
